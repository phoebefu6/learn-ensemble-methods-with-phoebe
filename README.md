# Learn Ensemble Methods with Phoebe

Six sessions on the tabular champions: bagging, random forests, gradient boosting, XGBoost, LightGBM, CatBoost, SHAP - with real trees fitted live in the browser.

**Live:** https://phoebefu6.github.io/learn-ensemble-methods-with-phoebe/

- Running project: predict Mango Lane churn on a deterministic 300-customer sample (200 train / 100 holdout)
- `assets/ensemble-live.js` is a genuine in-browser engine: greedy split-search trees, Newton-leaf gradient boosting, bagged forests - up to 600 real trees per click
- The measured ladder: one tree 58% holdout, forest 68, careless boosting 68 (train 100, gap 32), tuned boosting 73, 600-trees-forever 70
